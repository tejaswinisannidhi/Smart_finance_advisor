# Smart Finance Advisor

Smart Finance Advisor is a full-stack personal finance management application designed to help users manage their financial activities efficiently through a secure and user-friendly platform. The application enables users to track income and expenses, maintain transaction records, and receive AI-powered financial insights for better financial awareness and decision-making.

The project was developed using modern web technologies with a focus on frontend-backend integration, authentication, database management, REST APIs, and cloud deployment practices.

## Features
- Secure User Authentication using JWT
- Income and Expense Tracking
- Transaction Management
- AI-powered Financial Insights
- Responsive and Interactive User Interface
- Cloud-based Deployment

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT
- Deployment: Vercel & Render
